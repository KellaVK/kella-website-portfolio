# Kella Kruebbe — Personal Website

Static magician portfolio with performance imagery, gallery, biography, and booking/contact interface.

## Run

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`. No build step is required.

## Structure

- `index.html`: main landing page from the existing GitHub repository.
- `gallery.html`: gallery from the same repository.
- `assets/js/`: extracted page scripts.
- `images/`: recovered local assets, with filename case aligned to existing references.
- `about.html` and `contact.html`: additional local pages retained at their original URLs.
- `docs/SOURCE.md`: source-selection notes.

Booking behavior uses the existing third-party integration. Validation does not submit inquiries. The journal and performance tools have separate repositories.
